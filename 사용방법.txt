모션로그 — 6가지 운동을 기록하는 개인 운동일지

1. index.html 파일을 더블클릭하면 브라우저에서 사이트가 열립니다.
   index.html과 style.css, app.js는 같은 폴더에 있어야 합니다.
2. 운동 종류를 고르고, 날짜와 기록을 입력한 뒤 '운동 기록 저장'을 누릅니다.
3. '운동일지'에서 저장된 기록을 찾고 수정·삭제할 수 있습니다.
4. '운동 노하우'에서 각 운동마다 작성한 자세 메모를 관리할 수 있습니다.
5. '신체 변화'에서 키/체중/골격근/체지방을 입력하고 그래프를 확인합니다.
6. '몸 사진'은 브라우저의 사진 저장소에 보관됩니다.
7. '마이페이지 → 전체 기록 백업'에서 사진을 포함한 JSON 백업 파일을 저장하세요.

주의 사항
- 이 버전은 개인 저장형 앱입니다. 별도 계정/서버가 없으므로 다른 기기와 자동 동기화되지 않습니다.
- 브라우저 기록/사이트 데이터를 삭제하면 데이터가 사라질 수 있으므로 주기적으로 백업하세요.
- 위치 기반 운동 장소 검색은 HTTPS 웹 주소에서 실행하는 것이 좋습니다. 지도 서비스 링크는 직접 열 수 있습니다.
- 등산 예상 소요 시간 및 실제 운동 시설의 정보는 검증된 데이터가 없는 경우 임의로 제시하지 않습니다.
- 인터넷이 연결되지 않아도 기본 운동 기록은 사용할 수 있습니다. 글꼴/지도/외부 서비스는 인터넷 연결이 필요합니다.
- 실제 회원가입, 여러 기기간 클라우드 저장, 공공데이터 자동 업데이트를 원한다면 백엔드 서버/API 연동이 추가로 필요합니다.

웹사이트 게시
- GitHub Pages, Netlify, Vercel 등 정적 웹 호스팅에 폴더의 파일을 업로드할 수 있습니다.
- HTTPS 웹 주소로 열면 홈 화면에 추가 가능한 PWA 기능을 활용할 수 있습니다.
